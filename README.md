# From Structure to Function: Preference Alignment for Function-aware Protein Inverse Folding

Official code for "From Structure to Function: Preference Alignment for Function-aware Protein Inverse Folding" [KDD 2026](https://yuangang-pan.github.io/Publications/KDD2026.pdf).


## Overview

This repository hosts implementations of preference alignment for function-aware protein inverse folding across multiple backbone models.

## Repository Structure

- ProteinMPNN implementation: [ProteinMPNN/README.md](ProteinMPNN/README.md)
- ESM-IF implementation: [ESM-IF/README.md](ESM-IF/README.md)

## How To Use This Repository

For setup, data preparation, training, and evaluation steps, please follow the README in each model-specific subdirectory.

The root README is intentionally kept as a high-level index and does not duplicate instructions from model-specific READMEs.
